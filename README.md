FamilyPay — концепт мобильного банковского приложения для всей семьи. Это одностраничное веб-приложение (SPA) на чистом HTML/CSS/JavaScript без внешних библиотек, которое демонстрирует современный подход к семейным финансам: общий бюджет, карманные для детей и пожилых, защита от мошенничества и геймифицированное обучение финансовой грамотности.
